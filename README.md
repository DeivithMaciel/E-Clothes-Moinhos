# E-Food

Projeto desenvolvido como trabalho final da formação Engenheiro Front-End da EBAC.

A aplicação simula uma plataforma de delivery de alimentos, permitindo visualizar restaurantes, consultar cardápios, adicionar produtos ao carrinho e concluir pedidos através de um fluxo completo de checkout.

## Tecnologias

- React
- TypeScript
- Redux Toolkit
- Styled Components
- React Router
- API REST

## Funcionalidades

- Listagem dinâmica de restaurantes
- Visualização de cardápios
- Carrinho de compras
- Controle de quantidade de itens
- Checkout com formulário
- Integração com API REST
- Gerenciamento global de estado com Redux

## Objetivos do Projeto

Este projeto foi desenvolvido para consolidar conhecimentos em:

- Componentização
- Gerenciamento de estado global
- Consumo de APIs
- Tipagem com TypeScript
- Navegação entre páginas
- Boas práticas de desenvolvimento Front-End
